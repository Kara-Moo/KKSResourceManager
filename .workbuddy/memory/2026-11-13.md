## 追加：交互增强 + 自由修改模式 + 隐藏文件夹（第三轮）

### 新增文件
- `invisible.go` —— 空文件夹隐藏索引与路径重建
- `clipboard.go` —— 复制/剪切/粘贴
- `preview.go` —— 缩略图（第二轮已加，本轮扩展 GetFolderPreview）

### 隐藏文件夹机制
状态存于 `DELCARDS/DEL-invisible/`：
- `KKSinvisible.json` / `DELinvisible.json` —— 被隐藏的文件夹（相对各自根的路径）
- `OriginKKS.json` / `OriginDEL.json` —— 原始目录树（只记文件夹，不记文件）

关键设计：隐藏的是**目录树**而非单个文件夹，因此恢复时能把整棵子树还原。
隐藏前校验递归文件数为 0，否则报「无法删除，不是空文件，存在 N 个文件」。
`EnsurePathForOperation()` 在隔离/恢复前检测父目录是否被隐藏删除，是则重建。

### 关键安全决策（重要）
1. **zipmod 以扩展名判定，而非 GUID 是否解析成功**。
   若按 GUID 判定，manifest 解析失败的 zipmod 会绕过依赖检查被移走 → 造成依赖缺失。
   现在 GUID 为空时**保守拒绝**移出并提示「无法识别 GUID，无法确认依赖关系」。
2. **zipmod 的「复制」语义等同移动**：从 mods→隔离区是隔离（源必须移走），
   从隔离区→mods 是启用。否则「复制到隔离区」等于没隔离，源还留在 mods 里。
3. **同名冲突整体取消**：粘贴时预检全部目标，任一冲突则整个操作取消并报「无法复制」。

### 交互变更
- 点击行 = 只切换焦点（不勾选）；焦点行浅蓝底 `.is-focused`，长名换行完整显示
- 非焦点行长名截断（CSS text-overflow: ellipsis，max-width 320px）
- 勾选文件夹级联勾选全部子孙（`collectDescendants` 按 path 前缀匹配）
- 文件夹焦点时右侧显示统计 + 2x2 窗格（最多 3 个子文件夹 + 1 个「还有 N 个」）
- 模式切换按钮：自由修改模式(红) / 安全加载隔离模式(绿)
- 右键菜单：自由模式=复制/剪切/粘贴；安全模式=隔离(左)/启用(右)
- 新增管理种类「隐藏的文件夹」，其下隔离/启用按钮禁用，显示恢复按钮

### 验证
59 个测试通过 · `go test -race` 干净 · 真实目录 E:\DELCARDS\DEL-invisible 下
四个状态文件已自动创建并格式正确

### 关键架构决策（写进规格书）
- 索引只持久化正向数据，反向图每次 `derive()` 派生，禁止双写。
- 破坏性操作全部走 Tx（预检→计划→执行→journal 逆序回滚），崩溃启动自动回滚。
- 删除 = 移入 `_trash`，不做真删；移动不预复制（journal 即可逆），避免 40GB 备份。
- 状态文件/索引/缩略图缓存全部放 `DELCARDS/_state`，绝不写 KKS_ROOT。

### 关键经验（重要）

1. **静态检查工具别做字面量剥离**：最初写了 stripLiteralsAndComments，
   正则字面量 `/[\"']/` 被误判为字符串起始，吞掉后续代码产生误报。
   改为直接对原文扫符号表，反而 100% 准确。工具支持可选路径参数，
   能对 `git show HEAD:frontend/index.html` 这样的历史版本跑检查自证。

2. **改变契约时，旧测试会红，要分清是回归还是该改**：FIX-02 后
   `TestPanelFocusSelected`（断言九宫格里有 Selected）失败 —— 它编码的是旧行为，
   应按新契约改写，而不是回滚实现。

3. **结构性问题要收敛入口，别只补一行调用**：FIX-01 的成因是
