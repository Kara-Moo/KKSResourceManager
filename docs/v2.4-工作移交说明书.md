## 1. 这个项目是什么

- **产品名**：KKS 资源管理器（KKS Resource Manager）
- **解决的问题**：KKS 游戏（KOIKATSU / KK 系）的 Mod 资源散落在 `UserData/chara/female` 等目录，玩家需要「隔离（移到备份区）/ 启用（移回）」「隐藏空文件夹」「回收站（删除=移入 `_trash`）」「缩略图预览」等能力。本工具是图形化前端 + 安全操作引擎。
- **两个核心安全语义**：
  - **安全加载隔离模式**：隔离 = 把资源移到 `DELCARDS/DEL-<类型>/<相对路径>`；启用 = 移回。游戏目录永不真删、空目录树保留。
  - **自由修改模式**：复制/剪切/粘贴普通资源文件。
- **最重要的红线（任何改动都不能破坏）**：用户「勾选哪些就只动哪些」，且**绝不造成 zipmod 依赖缺失**——但 v2.4 已经把 zipmod 整个移除，所以这条红线现在简化为「隔离/启用只碰选中的资源文件、不动游戏目录结构、不删空目录」。

## 3. 核心架构（必读，避免改错地方）

### 3.1 后端 ↔ 前端调用模型
- 前端通过 `window.go.main.App.<方法名>(args)` 调后端（Wails 自动生成 `frontend/wailsjs/go/main/App.js`）。
- 后端通过 `wruntime.EventsEmit(ctx, "事件名", payload)` 推事件给前端（扫描进度 `scan:progress`、完成 `scan:done`/`scan:complete`、索引失效 `panel:invalidate`、日志 `log` 等）。
- **前端入口只有 `frontend/index.html` 一个文件**，所有 JS 内联在 `<script>` 里。改前端 = 改这一个文件。

### 3.2 扫描/索引模型（v2.4 阶段 3 已重写）
- 索引文件：`DELCARDS/_state/index.json`（**绝不写进 KKS_ROOT**）。
- `SchemaVersion = 2`（见 `internal/index/types.go:26`）。
- v2 索引 **只存卡片的正向数据**：`Cards[绝对路径] = {size, mtime, kind, rel}`。**没有任何 zipmod / plugin / 依赖图 / GUID**。
- 增量扫描：只 `stat` 文件（size + mtime），指纹未变即复用、**不打开文件内容**、不解析 PNG、不读 DLL。这是「冷启动 ≤5s / 热启动 ≤300ms」的关键。
- 扫描进度回调 `ProgressFunc(phase, done, total)`（见 `internal/index/scan.go:19`）——**签名保持不变（前端契约）**，但 v2.4 起 `phase` 恒为 `"resource"`（单阶段）。

### 3.3 隔离区约定（红线级）
- `DELCARDS_ROOT = KKS_ROOT/../DELCARDS`
- 8 个标准子目录 `DEL-female_card / DEL-male_card / DEL-scene / DEL-pose / DEL-coord_f / DEL-coord_m / DEL-studio_char / DEL-zipmod` —— **只增不删**，清理时受保护（`manager.go` 的 `cleanEmptyDirs` 有保护名单）。
- **重要**：`DEL-zipmod` 是历史遗留目录（旧版本生成的）。v2.4 不再管理它，但**绝不能删它里面的文件**（`manager.go:617-621` 对 `DEL-zipmod` 内的文件一律「跳过、不改动」）。

### 3.4 三条红线（历史经验，仍适用）
1. 共享资源绝不被误移：移除勾选引用后若仍有其它引用者则原地保留（v2.4 已无 zipmod，但「选中的才动」原则不变）。
2. 隔离保留原目录结构（`DEL-<kind>/<相对路径>`），游戏目录空文件夹永不删除。
3. 恢复放回原位（`Rel` 还原），DEL 区空目录可清理，同名则跳过。

## 7. 阶段 4 详细规格（T9 bug，未开始 —— 阶段 3 提交后才做）

### 7.1 这个 bug 是什么（用户实证）
- **现象**：勾选**多个文件夹**点「确认隔离/恢复」时，前端把「文件夹路径 + 级联的子孙文件路径」一起传后端；顶层文件夹被后端递归搬空后，子孙路径再被单独处理，产生**多余的空目录结构**（表象就是「只建结构、内容处理乱」）。
- **根因（用户定型三条 B1/B2/B3 + 源侧空壳）**：
  - **B1**：找不到卡片被当空文件夹（错误地把非卡片目录当空目录处理）。
  - **B2**：只收 `IsCardFile` 丢非卡片文件（文件夹里若有非卡片文件，隔离后丢失）。
  - **B3**：先建目录后失败、回滚不回收目录（事务回滚只搬文件、不删已建空目录）。
  - 另加：源侧空壳从不清理（隔离后游戏目录留下空文件夹树）。
- **真实证据**：`E:\DELCARDS\_state\history.json` 有两条 isolate 记录 `affected=0` 且 `committed`（时间戳 20261113-205151/223648），证明「0 文件 → 走空文件夹分支 MkdirAll → 计为成功」确实发生过。
